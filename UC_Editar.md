## Código / Nome do Caso de Uso

| Código / Nome do Caso de Uso | UC_Editar |
|---|---|
| Ator Principal | Gerente de Sistema |
| Resumo | Neste caso de uso, o gerente de sistema vai editar os dados de um usuário cadastrado no sistema. |
| Pré-condições | O gerente de sistema deve estar conectado ao sistema e o usuário deve estar cadastrado. |
| Pós-condições | Os dados do usuário são atualizados e ficam salvos no sistema. |

## Fluxo Principal

| Gerente de Sistema | Sistema |
|---|---|
| 1. Seleciona a opção de editar usuário. | |
| | 2. Solicita os dados para localizar o usuário. |
| 3. Informa os dados de busca do usuário. | |
| | 4. Busca o usuário no sistema e exibe seus dados. |
| 5. Altera os dados desejados e confirma a edição. | |
| | 6. Valida as informações fornecidas. |
| | 7. Atualiza os dados do usuário no sistema. |
| | 8. Exibe uma mensagem informando que o usuário foi editado com sucesso. |
