# Especificação de Caso de Uso - UC_Cadastrar - Cadastrar usuário

## Código / Nome do Caso de Uso

| Código / Nome do Caso de Uso | UC_Cadastrar |
| ---------------------------- | ---------------------------------------------------------------------- |
| **Ator Principal** | Gerente de Sistema |
| **Resumo** | Neste caso de uso, o gerente de sistema vai cadastar um usuario no sistema. |
| **Pré-condições** | O gerente de sistema deve estar conectado ao sistema e tem que ter os dados do usuario. |
| **Pós-condições** | O gerente consegue colocaro usuario no sistema e ele tem acesso aos conteudos de la. |

---

## Fluxo Principal

| **Gerente de Sistema** | **Sistema** |
| ------------------------------------- | -------------------------------------------------------------------- |
| 1. Seleciona a opção de cadastrar usuário. | |
| | 2. Solicita os dados do usuário que será cadastrado. |
| 3. Informa os dados do usuário e confirma o cadastro. | |
| | 4. Busca o usuário no sistema. |
| | 5. Exibe os dados do usuário encontrado para confirmação. |
| 6. Confirma o cadastro do usuário. | |
| | 7. Adiciona o usuário do sistema. |
| | 8. Exibe uma mensagem informando que o usuário foi cadastrado com sucesso. |
